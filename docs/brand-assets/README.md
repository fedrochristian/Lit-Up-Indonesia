# Lit Up logo source

`litup-instagram-logo.jpg` is the 1080 x 1080 profile image downloaded from
[the @litup.id Instagram profile](https://www.instagram.com/litup.id/) on
September 25, 2026. The user identified this image as the Lit Up logo.

The JPEG is stored and embedded unchanged. It includes the yellow symbol,
LIT UP wordmark, and blue background. It is a raster reference, not a vector
master. The PDF's supporting palette and typography remain proposed directions.
